# gnss-and-gps-intergity-navigation-sysytem
GPS Interference Detection & Navigation Integrity Monitoring System

A comprehensive real-time navigation security platform designed to detect GPS signal anomalies, spoofing attacks, jamming attempts, and positioning integrity degradation using machine learning and sensor fusion.

Features
Real-time GPS data acquisition using ESP32 and NEO-6M
MPU6050-based motion and inertial sensing
GPS integrity assessment using Isolation Forest anomaly detection
Detection of:
GPS Spoofing
GPS Jamming
Signal Degradation
Satellite Visibility Anomalies
HDOP, PDOP, and satellite count monitoring
Real-time LED status indication
🟢 Integrity Normal
🔴 Integrity Compromised
Interactive aerospace-grade dashboard
Live telemetry visualization
Satellite sky plot visualization
3D Earth and satellite tracking interface
Historical anomaly logging
Real-time alerts and diagnostics
